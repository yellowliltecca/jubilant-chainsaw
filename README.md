# Дверьмакс — сайт компании

Статический адаптивный сайт на HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются.

## Запуск

Откройте `index.html` в браузере или разместите все файлы проекта на статическом хостинге (например, GitHub Pages).

## Что входит

- `index.html` — структура страницы, текст, телефоны, адрес, ссылки на карту.
- `styles.css` — визуальная система и адаптивная вёрстка.
- `script.js` — мобильное меню и автоматический год в подвале.
- `assets/hero-entry.webp` — сгенерированное изображение первого экрана.

## Важно перед публикацией

- На открытой карточке организации не обнаружена ссылка на официальный сайт. Контактные данные взяты из публичной карточки-справочника и должны быть подтверждены заказчиком перед публикацией.
- Форма обратной связи не добавлена: без подтверждённой почты, CRM или мессенджера она выглядела бы рабочей, но не отправляла бы заявки. Все телефонные кнопки ведут на реальные номера.
- Цены, отзывы, гарантированные сроки и неуказанные условия не добавлялись.
